Welcome to **Last Sword**! This is a 2D action/dungeon adventure game built with Godot Engine. 

The game's first version (v1.0) is officially playable! As this is an ongoing learning project, I will be updating and refining the gameplay, mechanics, and visual elements in future versions based on testing and feedback.

## ✨ Features & Gameplay Highlights

- 🗡️ **Combat & Movement System**: Fast-paced melee attacks, range/projectile attacks, dash mechanics, and defensive abilities.
- 👹 **Diverse Enemies & Boss Fights**: Face bats, snakes, zombies, and bosses with custom fight phases and taunts.
- 🗺️ **Multiple Environments**: Journey through jungles, ruined cities, and dark dungeons.
- 📜 **Story & Dialogue**: Story-driven level transitions with NPC dialogues and cutscene triggers.
- 🧪 **Power-ups & Buffs**: Collect items to boost stats and withstand tougher encounters.
